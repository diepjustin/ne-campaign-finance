Read this before quoting it

Summing the amount column over-counts. The state fans one transaction out over several rows that share an ID — an independent expenditure against five candidates is five rows, a contribution to a slate committee is one row per candidate — repeating the amount on each. Every row carries an include_in_total flag; sum where it is true. For 2022 contributions alone that is the difference between $68,865,363 and $68,955,221.
  • Only itemized transactions appear. Contributions below the roughly $250 aggregate threshold are reported as lump sums on a committee's summary page, never as line items. Totals built from line items undercount small money.
  • Amendments overwrite; there is no history. The amended column is a bare Y/N flag. A corrected filing replaces the original in place, so two pulls on different dates can disagree with no audit trail. Every dated pull is archived here because the state keeps no such record.
  • Each extract is a snapshot, not a ledger. Late and corrected transactions appear retroactively in prior years. No year is ever final.
  • A loan is not a contribution, and a bare pledge is not money — both are kept out of the contributions table on purpose. A $50,000 self-loan is borrowed, not raised.
  • 2022–2026 only. This is the FirstTuesday era. Filings from 1985–2021 sit in a separate, frozen state dataset that is not collected here yet.
  • Federal candidates file with the FEC, not the NADC.

Provenance

Downloaded from the NADC's bulk data page, most recently 2026-09-08. The state publishes column layouts, but the expenditures layout misnames three of its own columns and the transaction-type lists in both PDFs do not match the data, so the scraper checks every header against a confirmed layout and fails loudly rather than guessing.

Built 2026-09-08. Method, caveats and open work are in the project README. No analytics, no tracking, nothing loads from a third party.
